## 先确定一个可以验证的问题

每条预测先登记：决策时刻、信息截止时刻、发布时刻、计划买卖窗口、共同终点T、结果成熟时刻和版本。

主周期H仍未确认；约5个交易日只保留为原建议。本稿不填写涨跌幅、风险线、目标线、费用或样本门槛。必须先冻结这些参数再生成标签。

“收盘后看到信号”不能假设已在同一收盘价成交。下一窗口的实际价格只能用于事后结果；如需开盘过滤，过滤是新的决策时点，另存当时信息。

## 八类事件

| 编号 | 预测问题与标签 | 成熟与不可评估 | 未成交及路径限制 |
|---|---|---|---|
| E01 买入方向 | 规定买入方案到T的净收益R，按未定的d/u划分上涨、中性、下跌；边界必须互斥且穷尽 | T已结束且成交、估值、费用、权益数据齐备；参数未定或关键口径缺失则不可评估 | 未成交交易R为null，不记中性或零收益；方向可识别不代表路径可识别 |
| E02 净盈利 | 同一买入方案R>0；R=0是未盈利，不是亏损 | 与E01相同 | 未成交不记失败；与“涨过某幅度”分别报告 |
| E03 收益和期间风险 | 连续净收益、入场后最大不利变化MAE、峰谷回撤MDD；两种风险不混名 | T及必要全路径齐备；缺入场时刻、路径或除权标尺则部分或不可评估 | 买入当天高低价可能发生于入场前，不能默认整根日K都是持仓路径；给范围或另命名可识别指标 |
| E04 触线先后 | 目标先到、风险先到、T前均未到、先后不明 | 先后能确定或T到期；“均未到”必须等到T | 同日跨两线是先后不明；跳空、价格触及和按该价成交分开；新买股票的可卖限制另核 |
| E05 买入/持币 | 同W0和T下，买入策略与现金策略的财富差Delta | 两腿财富均可核算；未知撮合使结果不同则不可评估或只给范围 | 若规则是未成交继续持币，可核策略财富，但仍没有零收益交易 |
| E06 直接买/等确认 | 固定确认、最长等待、失效及后续买入规则后，比较共同T的财富差 | 两腿共同T成熟；未触发不提前删去 | 没有确认、太晚确认、确认但未成交都保留。收盘确认不能回填当日最低买入；等待不事后延长终点 |
| E07 继续持有 | 从当前状态起算新增收益、方向及风险 | T和权益数据齐备；历史买入成本不决定未来标签 | 已有持仓不虚构一笔新买；纯持有和含条件退出用不同策略ID |
| E08 卖出/持有 | 下一窗口卖出持币相对继续持有的共同T财富差 | 两腿到T后才成熟；卖出当天不足以评价优劣 | 可卖数量、部分成交/失败及剩余持仓必须明确；不引入卖空，也不是1减买入概率 |

每类事件在JSON中进一步明确输入、参考时点、标签、成熟、不可评估、未成交和路径不明处理。

## 四个很容易混淆的状态要拆开

1. **预测状态**：未估计、可评估、证据较弱、不可评估、过期。不可评估的概率为null，不是0。
2. **成交状态**：无需成交、窗口未到、已成交、部分成交、未成交、成交未知。没有成交记录不自动等于无法成交。
3. **结果状态**：未开始、未到期、成熟可评估、成熟仅部分可识别、成熟不可评估、不适用。到日期但数据未到齐，仍不能拿去训练。
4. **路径识别**：明确、同日双触线、入场日先后未知、跳空/成交未知、路径缺失、不适用。

个人账户风险暂停另列，不由预测概率覆盖。未知持仓仍能进行标准化市场研究，但不能给个人可买可卖数量。

## 同终点比较怎样核算

- **起点一致**：同一t和W0，同样可用现金、证券股数、既得权益与可卖条件。
- **终点一致**：T事前确定。等待入场和停牌不能事后给其中一腿更长的持有期。若研究“实际成交后H日”，这是另一个问题，应另立事件。
- **现金一致**：现金是否计息、未投入余额如何处理先固定，不默认收益为零或使用未核利率。
- **成本一致**：发生对应交易才按有效日期费用规则计成本；原历史买入成本/已实现亏损不再只扣一侧。
- **权益一致**：分红、送转、股数变化按台账处理。终点前已取得但尚未到账的权益，按冻结的应收计价法处理，避免现金腿和持仓腿不对称。
- **估值和变现分开**：终点盯市财富不保证能在T清仓。若选清算口径，须另固定退出窗口、费用和卖不出的处理。
- **假设结果如实标识**：两种动作沿同一实际行情作研究比较，不表示两种动作都真实发生；若不能识别成交，不能编造点收益。

基本对比为`Delta_AB = [W_T(A)-W_T(B)]/W0`。Delta正表示A在所定义终点财富高于B，零表示相同；具体概率仍需后续研究，当前没有估计。

## 未成交如何避免被隐瞒

必须同时报告：全部合格意图数、已成交/部分成交/未成交/未知数、标签可评估覆盖，以及已成交条件下的结果。

“买入后盈利概率”可以是已成交条件概率，但不能当作所有发出买入意图都会达到的成功率。等待没有触发时，交易盈利标签没有定义；如果策略明确持币，则到共同T的策略财富仍可以定义。这两件事都要保留。

## 路径不明不能靠默认获利解决

日K同日高点跨目标、低点跨风险线，没有足够信息确认谁先到。保存unknown及可识别上下界；不能默认目标先到，也不能删掉未知样本后让三类概率看起来覆盖全部。

触线只是价格事件；是否可卖、是否跳空、是否成交是另外的结果。首日新买或停牌等约束以核过的历史规则为准。本稿不替代历史证券状态和规则验收。
