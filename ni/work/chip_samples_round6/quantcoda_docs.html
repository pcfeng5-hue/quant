特色因子（Beta）

特色因子是登录后使用的按需计算功能。因子值只随当前请求返回，不保存到业务数据库。目前尚未通过公开 REST、Python SDK 或 MCP 提供；如需计算，请前往 打开特色因子 →

日期范围

单次最多 31 个自然日，开始日和结束日都计入。

请求规模

单次最多 20 个证券代码，并可选择 1–10 个因子。

价格口径

支持原始价格（raw）或后复权价格（hfq）。

页面预览最多显示前 500 行，下载 CSV 包含本次请求的全部结果。结果字段为 trade_date、symbol、factor_id、factor_version、adjustment 和 value；当前版本标记为 beta-1。因子仅用于研究，不构成投资建议。

Access control

认证与限速

REST 请求使用 X-API-Key；MCP 请求使用 Authorization: Bearer。两者使用同一枚 API Key。限速按账号与套餐执行，并通过响应头返回当前状态。

日调用量

FREE 100 次/天；付费套餐不限制日调用总量。

分钟频率

FREE 30 / PRO 200 / Expert 500 次/分钟。

超档试用

无权限接口每天可试用 2 次真实数据，之后返回 403。

响应头：X-RateLimit-Limit、X-RateLimit-Remaining；分钟频率超限返回 429 和 Retry-After。

Request contract

通用约定

约定说明
symbol证券代码统一带交易所后缀：000001.SZ、600519.SH、430047.BJ。裸代码返回 422。
日期请求与响应统一 YYYYMMDD（如 20260707）。
数值价格、成交量等返回真正的 JSON 数值，不是字符串。
行数上限无分页参数；每次调用按端点固定上限截断（常规 6000 行，财务类 20000 行），足够覆盖全市场单日切片。请用日期范围或过滤参数收窄。
错误401 缺少/无效 Key · 403 套餐档位不足 · 422 参数错误 · 429 超限。detail 为中英双语说明。
版本策略v1 内只做向后兼容的变更：新增端点、新增返回列、新增可选参数；绝不删除列、重命名列或改变字段语义与单位。破坏性变更将以 /v2 并行发布，v1 保留至少 6 个月弃用期并在更新日志公告。
