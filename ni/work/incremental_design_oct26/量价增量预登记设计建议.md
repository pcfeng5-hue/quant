# 量价增量研究：单一候选设计建议

设计日期：2026-10-26。本文只读既有协议与指标计算代码；未打开标签数据库、未查询标签值、未计算新增分组的频率或成绩。既有开发期结果已被项目看过，因此本轮属于继续开发，不能追认成未见测试。

## 研究问题与单一新增模型

问题：在已登记的 MA 结构之外，既有的“放量且收涨/收跌”状态，能否在相同日期上增加未来五个观测交易日方向的概率预测价值？

只新增一个模型 `M2_ma_volume_direction_hierarchical`，保留 `M0_laplace_constant` 与 `M1_ma_group_shrinkage` 作为对照。不另开阈值、周期、收缩强度或组合搜索。

1. MA 父组仍为 `up / down / other`，使用已登记的 MA5、MA10、MA15 排列及 MA15 斜率两个布尔信号。
2. 量价子组使用已登记的两个量价布尔信号：`volume_gt_1p5_prev20_and_close_rising`、`volume_gt_1p5_prev20_and_close_falling`。
3. 量价子组取 `spike_up / spike_down / other`。分别为两个信号 `(1,0)`、`(0,1)`、`(0,0)`。`other` 包括未放量、平收等情况，并不意味着无量价影响或价格无变化。
4. MA 三组与量价三组形成固定九格，全部报告。布尔信号只接受 0、1、NULL；两个相反信号同时为 1 直接报错；任一需要的信号为 NULL，则该日缺值，不作 0 填充。

量能定义继承原协议：当日成交量除以此前同一未复权价格段内 20 个观测日的成交量均值，均值不含当日；严格大于 1.5。收涨/收跌使用相同价格段内 `C[t]/C[t-1]-1` 的符号，严格大于/小于 0。阈值相等与平收均落在 `other`。当日收盘后才具备完整输入，不据此声称盘中可用。

## 固定概率公式

所有模型使用同一折、同一组完整特征且标签成熟的训练日期：

- `p0 = (k + 1) / (n + 2)`。
- `pMA[g] = (kMA[g] + 20 * p0) / (nMA[g] + 20)`。
- `pM2[g,v] = (kCell[g,v] + 20 * pMA[g]) / (nCell[g,v] + 20)`。

M0 使用 p0；M1 使用 pMA；M2 使用 pM2。两层收缩强度均固定 20。空父组严格回到 p0；空子组严格回到 pMA；记录训练格子样本数、正例数及明确的 prior-only 标志。这是固定的层级平滑规则，父组统计包含子组；不是独立先验的贝叶斯区间，也不产生置信度或有效独立样本量。

M2 的直接比较对象是同日 M1；M0 为次要参照。M2 改善只能归因于这个“量能阈值与价格方向的联合分组”整体，不足以隔离成交量的单独因果或预测贡献。

## 公平比较与时间隔离

- 共同有效样本要求两个 MA 信号与两个量价信号均非 NULL。每折 M0、M1、M2 的训练日期集合完全相同，验证日期集合完全相同。
- 必须在共同样本上重新计算 M0、M1 的 p0、父组概率及成绩。上轮 M0/M1 的原成绩保留在原文件，不直接与新 M2 得分相减。
- 同时提供“上轮有效日期 / 本轮共同有效日期 / 因量价缺值新增排除日期”的覆盖对账。覆盖缩减是可用性代价，不能藏在较好得分后面。
- 保留六个季度折、扩展训练窗与既有标签定义。训练信号日与实际标签结束日均严格早于折起点；验证标签结束日不晚于折终点。每折三个模型的参数整折固定。
- 最少训练行数仍为 100。若共同训练样本不足，三模型该折共同弃答。此为工程门槛，不是统计充分性的证明，不能为得到结果降低门槛。
- 使用已登记 2023—2024 开发期标签，保持已知除权除息与开发期末边界剔除。不得读取、生成或评分 2025、2026 的新标签。

## 评分、展示及结论边界

- 预设主要比较：全体共同有效验证日期的平均 Brier 差值 `M2 - M1`；小于零表示该开发样本内误差较低。
- 同时报告 M2-M0 的 Brier 差值、三个模型的自然对数损失，以及 M2-M1 对数损失差。不得因为次要分数较好而改换主要指标。
- 所有六折与合并结果同时展示，不挑表现好的季度、格子或方向。
- 仍用从原始开发期第一个锚点开始每隔五个锚点取一个的固定格点作敏感性报告。应先取固定格点、再和本轮有效日期求交，不能在过滤缺值后重新每五行取一行。
- 固定概率五箱 `[0,.2,.4,.6,.8,1]`；空箱频率为 NULL。每格/每箱样本数小于 20 的标记只用于提示稀疏，不认证为不可靠或超过 20 即可靠；不拟合校准映射。
- 列出每折九格 n、正例 k、预测 p、零变化计数以及 prior-only 标志，不按成绩排名。稀疏格仍按固定公式报告，不在结果出现后合并或删除。
- 五日结果窗口重叠，固定格点也不自动保证统计独立。此次不报告 IID 二项置信区间、不作显著性、收益率或真实胜率认证。
- 上涨事件仍是 `C[t+5]/O[t+1]-1 > 0`，零变化归非正且单列。它不是净利润、可成交收益或一次交易获胜的概率。

## 多重试验记录与验收

先前 12 个描述信号及 2 个概率模型保留，新增模型变体计数加 1。对照模型的共同样本重算不计作新的模型设计，但必须登记本轮对照样本变更。九格、六折与固定格点不是相互独立的新试验；同时也不能借它们寻找“最好一格”。

本轮完成条件是：在结果计算前写入合同与哈希登记凭证；产出完整共同样本台账、三个模型全部结果与复算材料；独立复核公式、时间边界、共同样本、缺值及空格回退；保留正负结果。没有“本轮必须打败对照”的条件。无论成绩如何，正式历史输入许可、实时可用、当前预测、交易执行等门禁均保持 false。
