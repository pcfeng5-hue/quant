## 筹码及其他明确缺口

1. 完整筹码历史未取得，`chip_estimates`为空。官方开源文档说明`stock_cyq_em`只提供近期90个交易日；本轮核查开源实现发现其用行情运行本地成本估算算法，而非取得每个账户真实持仓。不得把该窗口称作2023年以来完整筹码，也不在本轮新建估算数据冒充原始数据。[AKShare官方文档](https://akshare.akfamily.xyz/data/stock/stock.html#id198)、[对应开源实现](https://github.com/akfamily/akshare/blob/main/akshare/stock_feature/stock_cyq_em.py)
2. 逐笔/Level-2历史、完整基金持仓、连续历史流通股本和时点行业/主题分类仍缺，授权及费用未确认。
3. 去重后的完整新闻政策历史、原始首次公开时间与修订档案仍缺。已有公司公告不能替代整个新闻政策数据库。
4. 185页公告没有有效提取文字，需OCR或图页/空白页人工核对；本轮没有完成光学识别或财务表格标准化。
5. 解禁接口返回空。本次结果记为未取得记录，不等于证明没有解禁事件。
6. MACD、KDJ、MA等属于从行情计算的派生指标，按用户最新指示留到后续阶段。当前未生成或分析这些信号。

## 来源、时间与单位

- 行情来自腾讯和东方财富公开行情响应；财务、股东、交易线索及公告目录来自东方财富公开数据接口；公告原件来自其公开PDF地址。本轮并非交易所授权全量数据产品，也未取得对未来自动抓取或再分发的无限授权。
- `source_snapshots`保存完整请求URL、UTC取得时间、原始响应文件和SHA-256。`raw/`保留原始JSON，各种复权口径分别存储，不覆盖不复权行情。
- `daily_bars.volume`保留接口成交量，单位标注为手；金额字段为源接口成交额，需结合数据字典。换手率标记为百分数，1.68表示1.68%，不是168%。流通/自由流通股本口径尚未独立重算，不能直接当作历史流通股本事实。
- 财务及事件记录整体保存于`payload_json`，字段名、报告期、公告日期和空值不丢弃；未核对单位的字段不得自行当作元或万元。0、空值、未披露和采集失败分开。
- 本次复权及财务历史为当前供应商回看版本，可能包含之后的复权或修订。收到时间是2026年的真实取得时间，不是2023年采集日志；页面所述披露时间也尚未通过全部原件逐项认证。因此不能直接宣称数据库可以无偏复现当时信息。
- 原始响应里可能有事后涨跌统计、更新后的估值和比较值。保留原始数据便于审计，不意味着允许它们作为当时预测输入。进入分析前另建时点可用字段白名单。

## 数据表及使用方式

| 表/视图 | 用途 |
|---|---|
| `source_snapshots` | 每次原始响应及成功/失败记录 |
| `daily_bars` | 各来源、价格口径和快照的日线 |
| `source_records` | 财务、股东、公告及交易线索的源字段 |
| `current_daily_bars` / `current_source_records` | 每个数据集最近成功快照，避免重复累加旧批次 |
| `announcement_documents` | 公告PDF原件目录、来源与校验值 |
| `announcement_pages` | 按页提取文字、原件哈希及提取状态 |
| `coverage_gaps` / `quality_issues` | 覆盖缺口及异常 |
| `chip_estimates` | 筹码估计预留表，目前为空 |
| `project_reference_documents` / `research_source_catalog` | 既有研究资料、用户要求和来源链接；不作为历史市场特征 |

旧快照用于审计；不能把多个来源、三种复权口径或多个快照相加当成独立交易日样本。来源记录的参考日期含义见`date_field`，不统一解释为交易日。

SQLite标准文件可以直接交给数据库工具使用。采集、公告归档、文字提取和质量检查脚本均保存在同目录；本批截止日固定为2026/10/13，没有启用后台更新或交易账户连接。

## 本轮质量检查与界限

[质量核对结果](./质量核对结果.json)记录10项检查通过：数据库完整性、日期范围、价格逻辑、去重、源文件和PDF哈希、双源日期一致及不复权价格/成交量一致等。912个共同日期无差异。

这不证明来源准确无误、历史全集完整、新闻时间可信或模型有效。文字提取仅确认有文本，不证明表格和数字正确。浏览页数据及JavaScript完成静态检查；本机浏览器策略阻止本地文件预览，因此未完成图形界面的运行验证。
