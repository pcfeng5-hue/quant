# 历史筹码逐价档数据渠道核查（2026-10-17）

本次仅检索 2 组聚焦问题，并阅读供应商公开产品文档。未操作项目浏览器，未登录、注册、付费、安装、调用需要权限的数据接口，也未执行第三方代码。

## 结论

1. **东方财富网页原始逐价档历史数值：本轮未找到可验证的公开导出或公开批量服务说明。** 这只是本轮公开资料核查的结果，不等于该公司没有此产品或能力。没有找到能解释项目已见“同一历史日读数随加载条件改变”的官方初始化、取样范围或复权说明，因此仍不能确认原因。
2. **Choice 官方帮助有筹码显示与通用数据导出说明，但两者不是同一项承诺。** 帮助页的“筹码分布怎么看”说明进入技术分析界面；数据浏览器部分说明可导出提取结果。页面未列明“历史筹码逐价档价格和比例”能否成为导出字段，不能据此宣称已存在完整筹码导出。
3. **Tushare 有供应商自家正式文档明确列示的候选数值渠道。** `cyq_chips` 说明各价位占比、2018 年起的历史范围，字段 `ts_code / trade_date / price / percent`，单次最多 6000 行，可按代码和日期分批。文档列出 5000 积分权限门槛。**这只是文档能力，尚未取得 002414.SZ 实际样本或核验完整覆盖。**
4. Tushare 的说明将其计算方法描述为三角分布与历史筹码搬移/衰减；来源标为 Tushare 社区。其结果属于该供应商口径，**不是东方财富网站原值，不是真实逐账户持仓，不可直接合并覆盖网页证据。** 当前公开段落未充分给出初始化日、价格网格、企业行动/复权、历史版本重算和历史时点可获得性信息。
