日期：2026年10月16日，加拿大多伦多。状态：可审阅设计稿，研究协议尚未冻结。本文细化已认可的研发方向；周期、交易阈值和新增风险数值没有据此自动确定。

## 1. 核心目标与当前起点

核心产品是用当时可得数据估计未来收益及风险的概率预测引擎，帮助比较买入、等待、持有和卖出。纪律、仓位及风控约束预测的使用。优先检验预测有没有新增信息、是否可信，再检验是否能形成可交易优势；软件完成和模型有效分别验收。

当前仍为数据整理与核对阶段。正式数据库上一核查快照覆盖高德红外002414.SZ的2023-01-03至2026-10-15，共914个日线日期；本方案没有刷新到10月16日，没有计算指标、概率、历史收益或生成买卖信号。914个日期不等于914次独立交易。

东方财富网页已实际核对两日筹码摘要随日期变化，完整历史价格档仍未取得。新闻、历史状态及首次可得时间等缺口继续保留。详见[数据库报告](./高德红外数据库/查漏补缺报告.md)、[网页筹码核查](./高德红外数据库/东方财富网页筹码核查_20261015.md)。

## 3. 每个预测先写清的事件字典

每条记录保存：股票、决策时刻t、信息截止时刻、预计执行窗口、参考价格与有效条件、预测终点、标签成熟时刻、数据/特征/模型/规则版本。市场时间统一用Asia/Shanghai；向用户显示多伦多时间时使用实际时区转换，避免固定时差假设。

### 3.1 入场和方向

候选主问题：若按预先约定方式在下一可执行窗口买入，持有H个交易日后，扣除适用交易成本及公司行动影响，结果如何？

- 定义净收益R及互斥标签：R大于上界为上涨；R小于下界为下跌；两界之间为中性。边界包含关系和成本口径写入字典，三类概率合计为100%。
- 另定义P(R>0)，表示净盈利概率。它与“上涨超过指定幅度的概率”分别显示，不混名。
- H、两条标签边界和退出窗口尚未冻结。为单独比较其他期限或阈值而进行的研究计入试验预算。
- 下一窗口实际价格是事后结果，用于结果核对，不是t时点的输入。若采用开盘偏差过滤，过滤信息和决策必须发生在新的执行时点并留记录。
- 尚未成交、无法成交和结果未成熟各有状态，不能记成零收益或自动删去失败样本。

### 3.2 幅度与期间风险

在同一预测期限下，输出净收益的分布/分位区间、预期净收益及其估计不确定性、期间最大不利波动、风险线触及概率。价格波动和实际可实现损益分开；尾部少样本时不强行给精确估计。

“未来结果区间”描述下一次结果可能落在哪里；“概率估计不确定区间”描述当前估计有多不确定，两者不得混用。首版区间覆盖水平待预登记，实测覆盖也需检验。

### 3.3 目标和风险线先后

可研究在H内先触及目标、先触及风险线、两者均未触及；仅有日线且同日高低均跨线时标记“先后不明”，给保守边界或补更细数据。入场当天新买股票的可卖限制也必须进入执行规则，不能把当日风险线触及视为必然卖出。日K高低价不证明成交顺序或保证成交。

## 4. 买卖动作如何比较

首版建议只研究四种动作：空仓买入、等待、持仓继续持有、卖出后持币。减仓比例优化和日内做T放在后续阶段。

| 当前状态 | 比较对象 | 共同条件与输出 |
|---|---|---|
| 空仓 | 下一窗口买入 / 持币 | 相同资金和终点，比较费用后结果、下行风险及资金占用 |
| 空仓 | 直接买入 / 等待确认 | 等待条件、最长等待、失效和未触发处理事先固定；记录风险改善、错失与未成交 |
| 持仓 | 继续持有 / 下一窗口卖出后持币 | 从相同当前净资产出发，到相同终点比较净财富差异、继续持有风险与增量费用 |

卖出预测不等于100%减去买入概率。下跌概率也不直接命名为“卖出成功率”。若展示“卖出优于持有的概率”，须先定义共同基准、动作策略及可识别的结果事件；否则先显示方向概率、结果分布与预期差异。

等待不等于事后挑选最低点。当前已发生的历史盈亏单独记账，持有/退出的预测以从现在起的增量结果比较。未来“现在买/卖”一律指预测生成后可执行窗口，不在已经结束的收盘价假设成交。

## 5. 输入白名单与缺口如何处理

以下为按用途安排的候选清单，不表示已获得历史输入准入。首轮实验开始前，必需字段必须逐项验收；未通过则保留阻塞项，或显式缩小研究范围并登记影响。

| 用途 | 候选输入 | 准入条件及当前边界 |
|---|---|---|
| 必需底座 | 原始OHLCV、日历、公司行动、当时证券状态、来源与可得时间 | 价格/量多数已有双源核对；复权历史口径、状态和信息时间仍需结项，不能全体视为通过 |
| 市场背景 | 指定市场指数价格、过去波动/趋势 | 只用当时数据定义状态；两处跨源价格差异先裁定或明确固定来源；指数成交量口径未核不入模 |
| 第一组特征 | 价格位置、MA5/10/15、MACD/KDJ、成交量变化 | 公式、初值、预热、窗口及参数冻结；派生相近信号不当作独立证据 |
| 条件性特征 | 成交额、换手、流通股本 | 单位与历史分母未证实处停用对应字段；禁止用今天股本回填过去 |
| 核心增量组 | 供应商每日筹码档位、分位成本、集中/迁移 | 核历史覆盖、档位、算法/版本、复权、修订、首次可得及授权用途；网页摘要与完整分布分开 |
| 事件增量组 | 原公告/财务、政策新闻、交割/期权到期、除权除息、派息 | 分别保存事件日、公布日、首次可得和版本；新旧/重叠事件不重复当独立样本 |
| 后续扩展 | 行业历史、大单分类、机构披露、融资等 | 以真实历史覆盖及可得时间为准；分类代理不能直接解释成机构身份或全市场净入金 |

同一数据项至少保存：观察时间、首次公开候选时间、供应商时间、实际取得时间、原件/原响应哈希、版本与准入状态。事后取得的历史记录不自动证明当时可见；时间只有日期时使用明确保守滞后或暂不入模，并披露限制。

原始价用于成交及持仓核算。研究特征采用一致、当时可重建的价格口径；未来公司行动导致的前复权重写不能静默改变过去输入。收益核算按实际权益记录现金和股数，不把除权机械变动当预测下跌。缺失不填0，不把未知当“无事件”。

筹码继续作为优先专项。可先完成价格/成交量基线的工程准备；运行该基线需其输入验收。完整筹码未通过前，不声称完成“含筹码模型”。比较有/无筹码时使用相同可用日期与口径，并另报告覆盖损失；不把不同市场年份的差异误认为筹码贡献。线上缺筹码时不得静默换成未经单独验证的模型。

## 6. 首轮研究怎样做

首个建议假设：在价格回落之后，等待事先定义的反转确认，是否比回落后直接买入带来更好的费用后收益与下行风险组合？退出/持有使用相同期限另设评估，避免由买点有效自动推定卖点有效。

1. 保存输入快照、排除日志和完整日序列。开发人员只接触开发允许范围内的成功、失败、中性、无信号、缺失、无法成交及未成熟结果；校准与封存测试结果按阶段隔离，不能提前用于信号筛选。
2. 建立同标签/期限的历史基础概率和同市场状态基础概率，只使用当时已成熟结果；经济对照另含持币及明确的持有方案。
3. 先做可解释的条件频率及少量信号检验。样本稀少时按预登记方式向基准收缩或拒绝估计，不能把少数成功显示成极高可信度。
4. 视样本支持程度，比较一个简单正则化概率模型；收益分位和风险估计同样从简。模型更复杂必须产生新证据，不能仅为复杂而升级。
5. 在有限组合中直接估计联合条件，不相加或相乘单信号概率。先评估单组新增信息，再做预登记组合。
6. 初始研究累计最多36个配置，保留完整试验台账。改变特征、阈值、期限、状态、校准/动作方案均登记；所有失败和无优势结论保留。预算分配在运行前确定，不据结果补名额。以后开展新研究批次须事先登记范围和预算，继续披露全部历史尝试与选择影响，不能重置累计试错或反复筛同一封存段。

模型输出的“相关因素”是关联或模型解释，不标为因果。新闻文本分类可辅助整理；事实、首次可得和来源仍须核对，不由语言模型直接生成已校准交易概率。

## 7. 概率怎样验证

顺序为：开发段内部向前滚动选择候选 → 更晚且未用于拟合的校准段 → 最后封存测试 → 冻结后的逐日前向观察。长度按有效事件和行情覆盖决定，暂不机械写成固定比例。

- 每个拟合时点只用已成熟标签；结果跨入下一阶段的样本从此前拟合中清除。隔离按标签结束时间处理，不能只排日期或套一个默认gap。
- 标准化、填补、特征选择、状态阈值及校准只在相应允许的数据上拟合。共享过去特征窗口不一律视为泄漏，重点检查未来结果、全数据预处理及修订信息。
- 已讨论、看过并用于改规则的高德红外/长城军工时期，不能重新命名为未见测试。若没有足够可证明未使用的历史区间，就依靠冻结后的新行情，明确等待。
- 记录原始预测数、去重触发数、重叠持有期和独立行情段；区间和敏感性检查考虑时间相关。三次已核分红事件不能支持任意精度的事件概率。
- 最终测试用来接受或拒绝；若根据其结果改模型，该区间已经消耗，新版需要新的评估数据。最终测试期间不得换阈值或挑最好阶段。

时间顺序与独立校准的实现依据分别见[TimeSeriesSplit](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)和[概率校准](https://scikit-learn.org/stable/modules/calibration.html)。单独使用这两个工具不自动解决重叠标签、数据修订或选择偏差。

## 8. 两张独立成绩单

| 验收层 | 必须报告 | 通过原则 |
|---|---|---|
| 概率预测 | 时间外Brier/对数损失与基准差；分组预测与实际频率；样本数/不确定区间；收益区间实际覆盖；不同阶段表现 | 校准与区分能力一起检查；Brier变小不单独证明校准更好；改进证据及容差在最终评估前冻结 |
| 交易效果 | 冻结动作规则下净收益、基准差、风险占用、回撤、期间不利波动、成本压力、未成交与尾部 | 预测改进能否覆盖执行成本及风险；买入和退出分别评价；不因某一指标漂亮而掩盖另一项未过 |

暂不设“必须70%胜率”或必达年收益。最小有效事件、区间宽度、最低可交易优势、最大风险和成本容差在实验运行前写定；当前没有实测证据足以合理填写。允许结论为“概率改善但不能交易”或“没有发现可靠优势”。

执行评价按证券、日期和适用规则处理可卖数量、交易单位、价格限制、停牌、部分/未成交与费用。日线成交模型无法证明排队成交，须披露并做保守压力。现行深交所相关依据见[2026年交易规则](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)，历史回测还需匹配历史有效规则及费用，不能把现行规则回填全部年份。人工确认不自动意味着无需核查程序化交易要求；上线前按正式通道和实际功能再核实。

## 9. 用户每天看到什么

预测卡建议默认显示下列内容，详细审计信息折叠保存。尚无估计时显示“未估计”，不填演示百分比。

| 卡片内容 | 说明 |
|---|---|
| 股票、时间、有效期 | 预测编号、截止信息、H、下一执行窗口；数据滞后显式显示 |
| 预测结果 | 上涨/中性/下跌、净盈利概率、净收益分位区间和期间风险 |
| 证据程度 | 同类事件数、时间外评估、不确定性、模型适用范围；解释当前不足 |
| 动作比较 | 空仓买/等或持仓持/卖；预期差异、费用、价格适用范围 |
| 条件与约束 | 已满足/未满足条件、事件、失效条件、既定退出计划；账户不明不报可买金额 |
| 执行反馈 | 是否执行、实际数量/价格/费用、偏离原因和最终成熟结果 |

预测状态：未估计、可评估、证据较弱、不可评估、已过期。行动状态单独显示：研究观察、等待、风险暂停、不可执行；只有通过后续准入后才出现经批准范围内的行动建议。

不可评估的常见原因包括关键数据缺失、时间/口径冲突、样本不足、超出历史支持、近期可靠性失效。它不等于上涨概率为0。一个上涨预测也不自动放行新增仓位。

## 10. 更新与模型失效

数据到达后先核质量，预测生成后不可覆盖旧版本。结果到期再回填实际结果，保留预测当时的内容。数据修订另存新快照，不偷偷改好历史成绩。

先积累可追溯预测日志；监控周期、概率恶化和数据漂移判据在部署前预登记。重要新闻可触发“原预测失效/重新评估”，不临时改规则追随行情。模型重训与版本晋级分别审批/记录，先离线和前向检验，不因连续几笔盈亏自动替换。

新增市场数据每天变化，不代表参数每天改动；“更新预测”和“更换模型”分成两件事。旧版失效允许暂停，不能由零散胜负强行认定恢复。

## 11. 资金、风险与用户参与

研究阶段用户只需确认首版优先周期；不需要先提供并不存在的数据渠道或写代码。可以逐步补充历史交易用于理解实际习惯，不凭自述计算胜率。

进入模拟/试验后，记录系统现金、持仓、买入日期、数量、可卖数量、成交价、实际费用、未完成订单和资金出入。外部手工交易必须对账。没有持仓信息仍可显示市场研究预测，不给具体可买股数或金额。

10,000元试验的2,000元已实现亏损暂停线保留原意；净损益费用分摊、在途订单和恢复规则在实施前补清。浮亏另列，含浮亏净值保护及单笔/仓位约束仍待讨论具体数值；此暂停线不保证账户总损失不超过2,000元。
