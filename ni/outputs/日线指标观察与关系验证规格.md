# 日线指标观察与关系验证规格 v0.1

2026-10-14需求补充：[信号组合与条件概率研究规格](./信号组合条件概率研究规格.md)。用户明确希望用市场数据统计不同组合后的上涨/下跌概率，替代相对价格及怕错过驱动的买卖；首版波段/盘中做T优先级、预测周期与标签阈值尚待确认。以下保留原日线计算规格，不能据此验证盘中做T。

日期：2026年10月9日。用户指定首批观察：股价走势、MACD/KDJ拐点、日K、MA5/10/15、筹码变化、成交量变化、换手率与股价关系。已记录为研究需求，不等于这些指标已被验证有效或都必须成为买入条件。

## 输入及展示

日线输入：证券代码、交易日期、开高低收、前收盘、成交股数、成交金额、停牌标记、当时流通股本及其口径、复权/公司行动信息、来源与可用时间。数据单位、价格口径、重复日期及缺失先校验。原始成交量不随价格复权任意调整。

第一版观察图规格：主图为日K+MA5/10/15；副图为MACD、KDJ、成交量和换手率；有可解释来源时添加筹码估计图或成本区间。标注已核实公告/事件，并区分当时可用与事后发布。尚未实现该图，也未收到用户实际数据。

## 指标口径

| 信息 | 候选计算/观察项 | 需要固定的细节 |
|---|---|---|
| 日K与价格 | 日收益、振幅、跳空、收盘位置、回调幅度 | 使用真实价或时点复权价的目的分别记录；停牌不能插成真实成交日 |
| MA5/10/15 | 最近5/10/15个有效日线收盘简单均值；斜率、价格偏离及相互排列 | 窗口不足输出缺失；是否包含停牌日先定；参数是用户指定观察周期 |
| MACD | 研究初始方案为12/26/9；DIF=快EMA−慢EMA，DEA为DIF的EMA，柱线比例另记 | 尚未与用户客户端口径核对；EMA初始化、预热、柱线DIF−DEA或2倍须固定；不得混用 |
| KDJ | 研究初始方案9/3/3；RSV由窗口高低与收盘计算；K/D递推平滑，J=3K−2D | 平滑方法、初值和高低区间为0时的处理待固定；TA-Lib STOCH不自动等同客户端KDJ；J不强制截断到0—100 |
| 成交量 | 当日量/此前N日平均量、缩放量、量价分组 | 股与手不可混用；比较窗口不含当日；放量不是看多事实 |
| 换手率 | 当日成交股数/当时指定口径流通股数 | 明确普通流通或自由流通，禁止用今天股本回填历史；成交量与换手率并非完全独立证据 |
| 筹码估计 | 成本分布、区间宽度、估计获利比例及迁移 | 若来自供应商须保存算法口径/版本；无法取得算法时标记黑箱估计，不能称为真实账户持仓或机构吸筹证据 |

实现参考：[TA-Lib动量指标](https://ta-lib.github.io/ta-lib-python/func_groups/momentum_indicators.html)、[TA-Lib随机指标说明](https://ta-lib.org/functions/stoch.html)、[通达信官方公式函数说明](https://help.tdx.com.cn/gspt/docs/markdown/redword/functionlist.html)。用于核对计算，不为交易有效性背书。筹码成本估算的假设可参照[长城证券公开客户端帮助资料](https://www.cgws.com/fintech-oss-monthnews/cczqsdbhelp.pdf)，该资料为旧版软件说明，不代表本项目取得当前产品数据或一致算法。

## 拐点与买点必须分开

仅研究当时能够判断的拐点。示例候选：指标上一日变化≤0、当日变化>0，称为当日观察到的转向；交叉、斜率转向、柱线变化分别记录，不合并为一个含糊的“金叉”。

若某种局部低点定义需要未来几日确认，则确认时间必须延后，不能把信号画回低点当天用于买入。盘中尚未完成的日K与收盘后确定值分开；日线首版使用完成日K，随后合法时段才可执行。

MACD、KDJ、均线均派生于价格，多个同时变好不能视为多份独立证据。必须与基础价格条件比较新增信息；筹码若也由量价和换手估算，同样检查重复信息。

## 关系验证

1. 先建立固定时间线观察，不挑只成功的拐点；覆盖上涨、震荡、下跌和失效案例。
2. 同期相关只用于描述，预测验证须用截至t的信息对应随后实际可执行交易的表现。未来收益可作研究标签，不能作输入。
3. 分别检验：仅价格基线、加入均线、MACD、KDJ、量/换手、筹码；再少量测试事先登记组合。不强行要求全部同日满足。
4. 目标持有周期和标签窗口在研究前确定；未来1/5/10/20日等只是候选，不全试后择优而不计入试验数。重叠标签的验证留出间隔并按时间切分。
5. 评估样本数、收益/亏损分布、尾部、费用后收益、回撤及机会损失；用其他股票和未参与设计时段检验。遵守原36次试验预算和封存审计要求。

验收先看计算：与确定参数和口径的参考软件/独立实现交叉核对；用常数价格、单调走势、除权、停牌、缺失、极端换手与窗口不足测试。计算一致不表示能预测。

当前完成：需求与规格。未完成：输入解析、指标计算、绘图、历史关系报告或预测模型；下一步在基础数据源确定后实现观察工具。
