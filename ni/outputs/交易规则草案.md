# 交易规则草案 v0.1

日期：2026年10月7日。状态：需求与研究设计，尚未成为可实盘执行策略。

补充研究：[机构公开风控资料与个人量化规则手册](./机构公开风控资料与个人量化规则手册.md)，包含原始资料索引、20项实现控制、研究参数提案和压力测试示例；提案不等于已确认实盘参数。

用户明确：目前没有固定、理性的入场信号标准；建立标准与规则是当前最重要的工作。无需强行把既有主观判断包装成成熟策略。

## 目标

优先处理信号不足时提前买入、盈利卖出后急于重新入场、难以空仓和一次投入过大仓位。策略应同时具备可计算的入场、仓位、退出与暂停规则；纪律不能代替策略有效性验证。

## 第一层：系统行为要求

以下为拟实现要求，尚未编码；证券范围和金额明确标注来源。

| 编号 | 要求 | 如何验收 |
|---|---|---|
| R01 | 排除ST；将*ST一并排除作为实现草案，持仓后被风险警示另定处理规则 | 历史状态与当日状态分别校验，排除标的不产生新增买单；不可用今天的ST状态替代历史状态 |
| R02 | 无合格信号可持续空仓，不设交易次数配额 | 连续无合格信号的测试区间内新增买单为0 |
| R03 | 每笔买入必须有预定义条件和有效数据支持 | 每项必要条件失败或缺失时均能拦截，并记录原因；不能用综合分数覆盖必要条件失败 |
| R04 | 盈利卖出后再次买入须重新满足入场条件 | 仅有价格回落、过去盈利等条件时不能放行；不自动设置未经检验的固定冷静天数 |
| R05 | 单笔、单股与总仓位独立校验；待成交委托也占用额度 | 拆单、多次加仓和并发订单不能绕过限额；具体限额待研究与用户确定 |
| R06 | 每笔策略交易入场前记录退出及判断失效规则 | 缺少退出规则的策略配置不能进入模拟或实盘；实际卖出仍受市场约束 |
| R07 | 初期5万元累计交易亏损1万元时暂停新增买入并复核 | 采用明确且经确认的盈亏口径触发；阈值由用户提供，不保证实际亏损不会超过阈值 |
| R08 | 规则变更版本化，保存原因、时间与新旧差异 | 同一历史版本可复现；不能因某次被拦截就在运行中偷偷修改条件 |
| R09 | 订单、成交与账户持仓不一致时阻止新增风险 | 通过回报、查询和对账解决；人工通过券商客户端交易不能假定被程序阻止 |
| R10 | 对预定时间退出的交易，约束持仓后的临时延期；记录变更证据与审核，默认不得扩大风险 | 无合格变更依据时不得延后；具体范围与例外待研究，未编码 |
| R11 | 退出触发后进入待退出状态，禁止该笔交易继续加仓，按实际成交更新持仓 | 模拟跌停不能成交、部分成交与重启情景；发出卖单不等于退出完成，未编码 |

2026年10月9日补充依据：[长城军工口述案例](./交易案例01_长城军工.md)。新增要求不意味着这些控制已在风控原型实现，也不是对现有持仓的卖出指令。

用户已确认核心原则（2026/10/09）：不得为了额外利润随意改变风控计划。规则设计应拒绝仅凭“还会涨、再多赚一点”延后既定退出、放宽止损或增加原定风险；任何例外需独立定义、留痕与验证，不能成为临场绕过风控的入口。该原则已确认，具体参数和实施方式尚未确认或实现。

用户已确认第二条核心原则（2026/10/09）：对反转入场，必须等预先定义的反转必要条件全部满足且数据有效后才允许买入；接受少赚、错过和保持现金，不提前押注反转。仅有下跌、价格便宜或过去盈利不能放行，也不能以先买少量绕过条件；卖出后重新入场同样检查。“反转成熟”的可计算定义尚待制定与验证，不表示已获得有效交易信号，也不能保证合规买入后不亏损。此要求针对反转入场，不自动把所有候选策略改为反转策略。

## 第二层：需要研究后确定的策略参数

不在今天凭空固定均线周期、买入百分比、止损幅度或冷静时间。

| 模块 | 要回答的问题 | 研究产物 |
|---|---|---|
| 市场环境 | 是否存在适合该策略的可观测环境条件？过滤是否值得？ | 过滤前后、相同股票池与费用下的样本外比较 |
| 股票池 | 除ST外，权限、上市时间、流动性和数据覆盖如何界定？ | 当时可知的动态股票池规则 |
| 入场 | 哪些证据使“回落”成为可测试的入场假设？ | 明确计算方法、观察时点和最早可执行时点 |
| 仓位 | 信号通过后最多承受多少集中风险？ | 单笔、单股、行业、总仓位和待成交额度规格 |
| 加仓 | 是否允许，以及需要哪些新的证据？ | 独立加仓条件，不能因浮亏或价格更低自动触发 |
| 退出 | 哪些价格、时间或信号变化表明假设失效？ | 可测试退出条件，包含不能成交时的处理 |
| 重新入场 | 卖出后是否存在特别容易失败的再买入场景？ | 普通入场与额外限制的对照研究，避免无依据叠加限制 |

## 决策流程

数据有效 → 标的允许交易 → 必要策略条件满足 → 退出规则齐备 → 仓位与订单校验通过 → 生成模拟订单；实盘还须完成券商接入和上线验收。

任一必要条件失败或无法判断：不新增买入，记录拒绝原因。缺失数据不能当作信号不成立的正常市场证据，应单独报告系统问题。

## 验证计划

1. 在2026年10月14日前形成最多3种入场假设的规则卡，每张包括条件、时点、仓位约束、退出、失败情景和数据需求；这一步不要求策略已有效。
2. 在2026年10月21日前冻结第一批研究范围、比较基准、参数试验预算与规则规格，依照SMART路线图执行。
3. 所有候选共用数据口径、费用与可交易约束。保留全部失败实验，严格分离开发、验证、封存测试和前瞻模拟。
4. 分别衡量纪律效果与策略效果：前者检查是否阻止未满足条件或超限订单；后者检查费用后表现、风险、稳定性和交易机会损失。不能仅因买入次数变少就认定更好。
5. 未经验证的规则只用于研究，不对用户现有持仓生成买卖建议。

## 用户当前需要做什么

无需自行创造指标。后续帮助检查规则解释是否清楚、是否能够接受规则导致的等待和错过机会，并逐步提供真实案例用于验证问题描述。自动下单仍是最终产品目标。
